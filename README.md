## 如何填写课程内容

所有课程数据都在 `data.js` 的 `lessons` 数组中。找到对应日期和科目，把 `none` 换成真实内容，把 `null` 换成 0 到 100 的数字：

```js
{
  date: "2026-07-30",
  subject: "数学",
  content: "一次函数图像与性质",
  problem: "图像平移的判断还不够熟练",
  progress: 70,
  evaluation: "基础概念掌握较好，建议继续练习图像判断题。",
},
```

注意：

- 不要修改 `date` 和 `subject`，只填写其余四项。
- `content`、`problem`、`evaluation` 的文字必须保留英文双引号。
- `progress` 只填 `0` 到 `100` 的数字，不要加双引号或百分号。
- 暂时没有内容时保留 `none` 和 `null`，网页会显示“待填写”。
- 修改完成后，把文件顶部的 `lastUpdated` 改成当天日期。

## 发布更新

1. 在 VS Code 保存修改。
2. 打开 GitHub Desktop，确认左侧显示本次修改的文件。
3. 在左下角 **Summary** 填写本次更新说明。
4. 点击 **Commit to main**。
5. 点击窗口顶部的 **Push origin**。
6. 等待一两分钟后，刷新 `https://pageovo.github.io/agpt/`。

也可以在 GitHub 仓库网页中打开 `data.js`，点击铅笔图标编辑，完成后点击 **Commit changes**。建议固定使用一种更新方法，避免本地文件与 GitHub 网页版本不一致。

## 隐私提醒

免费 GitHub Pages 网站和公开仓库里的内容任何人都可能看到。不要上传学生真实姓名、学校、电话、住址、成绩单照片等敏感信息。如果需要限制访问，应改用带登录和权限控制的服务。
